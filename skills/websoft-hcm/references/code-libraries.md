# JS-библиотеки и OpenCodeLib

На Linux x64 HCM 2025.2.1333 (C-runtime) серверный OpenCodeLib загружает
JS-файл с объявлениями функций. Инициализация через верхнеуровневый
`var` в пробе дала `Code library may contain only function declarations`.
Объявляй локальные переменные внутри функций. Если ключ в обычном объекте
BorisScript необязателен, используй `GetOptProperty` с явным default.

```js
function label(options) {
  var defaultTitle = "Демо";
  return options.GetOptProperty("title", defaultTitle);
}
```

При вызове `OpenCodeLib(url).label({})` эта форма возвращает `Демо`.
При вызове с `{title:'Своё'}` возвращает переданное значение.

## Как проверить устаревший код

1. Сравни `LoadUrlText(url)` и результат вызова по тому же URL в том же процессе.
   Если чтение тоже возвращает старый текст, проверь хранилище URL. В пробе
   чтение увидело изменённый текст, а вызов продолжал выполнять старый код.
2. Для проверки новой версии используй отдельный временный URL. При первом
   вызове новый URL исполнил изменённый файл. Удали свой временный файл
   после пробы.
3. Для повторной загрузки опубликованного URL учитывай кеш процесса WT.
   В исходной проверке старый URL обновился после штатного перезапуска.
   `DropFormsCache` по шаблону не обновил библиотеку. Документация платформы
   отмечает отключение этой функции с 2025.2.1265.

Проверка охватывает JS-библиотеку на серверном C-runtime. Для библиотек в XML
и других окружений сначала уточни их модель загрузки.
