# WebSoft HCM: веб-администратор

Практические сценарии работы в браузере, независимо от компилятора и BorisType
MCP. Используй доступный browser tool и адрес целевой установки.

Для поиска сотрудника, открытия карточки и сверки полей прочитай
[сотрудники](references/employees.md). Там же описаны задержка полнотекстового
индекса, обычные фильтры и границы проверенного сценария.

## Работа с интерфейсом

- Начни с `/admin` на целевом сервере. На проверенной установке он открывает
  `/spxml_web/main.htm`; пользовательский портал и веб-администратор различаются.
- Находи элементы по актуальному snapshot/DOM, подписям разделов и полей.
  Координаты и UID из другого запуска непереносимы.
- Если полнотекстовый поиск не находит новую запись, очисти строку поиска и
  используй обычный фильтр или каталог. Пустая выдача не доказывает отсутствие
  объекта и не служит основанием создать его повторно.
- Перед снимком проверь видимые поля: карточка может показывать пароль открытым
  текстом. Для передаваемого изображения скрой его кадрированием или редактированием
  снимка, сохранив нужные поля и контекст записи. Не меняй сохранённый пароль
  ради скриншота.

## Пополнение знаний

Сохраняй в references назначение действия, видимые подписи, ожидаемый результат,
версию/среду и источник. Различай наблюдение браузера, пояснение пользователя,
документацию и API-проверку. Сначала проверяй новый маршрут на целевой установке;
не считай создание через API доказательством сохранения через UI.

Skill не предоставляет учётные данные или разрешение на изменение объектов.
Проверенные пути могут различаться по версии, роли пользователя и доработкам UI.
