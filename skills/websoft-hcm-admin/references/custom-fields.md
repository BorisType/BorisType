# Настраиваемые поля и страницы

Проверено в русском веб-администраторе WebSoft HCM 2025.2.1333,
Linux x64 C-runtime с PostgreSQL, 2026-11-20. Маршрут опирается на
браузерное создание, правку, сохранение и удаление временных настроек.
На другой версии сверяй подписи по текущему экрану.
[Поля и разделы в документации HCM](https://wshcm-docs.boristype.dev/news/monolith/6665632474391410577.html)

## Выбрать область

Открой веб-администратор через `/admin`. В нижней левой шестерёнке выбери
**«Настраиваемые поля…»**. В дереве слева есть два случая:

- **Общие поля типа.** Выбери, например, **«Подразделение»**. Изменение
  определения применяется к карточкам этого типа.
- **Шаблон одного типа заявки.** Открой **«Тип заявки»**. Если нужной
  записи в дереве ещё нет, справа нажми **«Добавить объект…»**. В окне
  **«Выбор объекта»** выдели существующий тип заявки и нажми **«Применить»**.
  Открой появившийся подраздел. Так настраивается форма для выбранного типа
  заявки. Тип заявки уже существует в каталоге.

Для просмотра достаточно открыть нужную область. Для пробы используй тестовую
установку, уникальный ключ поля и тип заявки без шаблона и существующих заявок.

## Добавить поля и страницу

1. У **«Подразделения»** нажми **«Новое поле»**. В **«Поле»** укажи
   тестовый ключ, например `bt_demo_department`, а в **«Название»** —
   «Пример отдела». Оставь тип **«Строка»**. «Поле» задаёт ключ
   определения, «Название» задаёт подпись в интерфейсе.
2. У выбранного типа заявки нажми **«Новая страница»** и укажи название,
   например «Детали». Затем нажми **«Новое поле»**, укажи свой ключ и
   название. В раскрывающемся списке **«Тип поля»** выбери
   **«Значение из списка»**, а в **«Страница»** — «Детали».
3. В блоке **«Список допустимых значений»** нажми плюс. В окне
   **«Редактирование записи»** введи значение и нажми **«Применить»**.
   Повтори для второго варианта. Сверь порядок строк. Для выбора
   нескольких вариантов в меню типов есть **«Множественный выбор»**.
4. Нажми кнопку окна **«Сохранить (Ctrl+S)»**. **«Применить»** в
   окне выбора объекта или значения завершает только этот диалог.
   Для проверки открой настройки снова и сверь область, ключ, тип,
   страницу и варианты. При правке существующего поля меняй нужный
   параметр и сохраняй окно заново.

## Убрать пробу

У общего типа удали созданное поле по его ключу. Если для пробы был добавлен
отдельный шаблон, удали его строку в **«Настраиваемых полях» → «Тип заявки»**.
Запись типа заявки остаётся в каталоге. Если шаблон существовал раньше,
удали только свои поля и страницы. Сохрани окно и проверь, что временные
настройки исчезли, а существующие остались.

В проверке создали строковое поле у подразделения и страницу с полем
из двух вариантов у одного типа заявки. Сохранение, переименование поля
и очистка прошли через веб-админку. Независимое чтение подтвердило
порядок вариантов и совпадение исходного XML после очистки.
Это проверка определений. Значения заполненных карточек и поведение
формы на портале в этом прогоне отдельно не проверялись.
