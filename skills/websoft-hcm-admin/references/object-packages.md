# Состав схемы и просмотр ZIP в веб-администраторе

## Текущий пакет

1. В каталоге, например **Сотрудники**, выдели нужные записи. Для добавления пользователь указал команду **ПКМ → Добавить в пакет**.
2. Открой **нижняя левая шестерёнка → Содержимое пакета…**. В окне **Объекты пакета** проверь название в поле **Схема** и добавленные строки на вкладке **Объекты базы**. Если нужны связанные объекты, сверь известные зависимости по списку. Строковый `mode` веб-шаблона и ID, записанные в `wvars`, могут потребовать отдельного добавления.
3. Для выгрузки в ZIP используй **Сохранить полный пакет…**. Кнопка **Создать пакет в базе** создаёт запись `upload_package` для обмена. Именованная схема хранит состав, из которого позднее можно снова собрать архив.

На вкладке **Настраиваемые поля** выбор `request_type` охватывает зарегистрированные шаблоны этого типа. Для переноса самих карточек типов заявок добавь их в **Объекты базы**. Это поведение выбора установлено по форме и сверено при сборке пакета на стенде.

## Что получит целевой стенд

Открой **верхняя шестерёнка выбора модуля → Системное администрирование → Обработка пакетов → Обработать пакет**. Выбери ZIP, нажми строку вложенного пакета и раскрой **Объекты каталогов**. Сверь нужные записи. Если задача состояла в просмотре, нажми **Отмена**. Изменения в базу вносятся отдельной кнопкой **Применить**.

Оба окна и предпросмотр с одним объектом проверены в веб-администраторе Linux HCM 2025.2.1333, Chrome 157. Просмотр завершили отменой. Команду контекстного меню сообщил пользователь.
