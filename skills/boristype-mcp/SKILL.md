# BorisType MCP

Используй доступный экземпляр BorisType MCP в пределах задачи пользователя.
Проверяй актуальные schemas и descriptions tools: этот справочник описывает
прототип с файловым API 2 и `wshcm_xquery`, а не все версии сервера.
Имя namespace MCP зависит от клиента; узнавай tools по суффиксу `wshcm_*`.
Если подключения или нужного tool нет, сообщи об этом; skill сам их не устанавливает.

## Выбор руководства

- Для поиска, чтения, редактирования и переноса файлов прочитай
  [работу с файлами](references/files.md). Там описаны цепочка readToken,
  диапазоны, повторное чтение и отличие физических файлов от SQL blobs.
- Для XQuery, `sql:`, точных ID, усечения и ошибок выполнения прочитай
  [серверные запросы](references/queries.md). Там есть SQL→XML ограничения,
  примеры text cast и границы timeout/повторов.

Точные параметры бери из schemas текущего сервера. Подробные ограничения
относятся к установленной версии; не подменяй отсутствующий tool придуманным
вызовом. Файловым tools нужна установленная BorisType.FileSystem DLL;
`wshcm_xquery` работает через серверный evaluator без этой DLL.

## Порядок работы

Установи, с каким сервером и хранилищем работаешь. Поиск по диску, чтение
логического URL и запрос к БД могут обращаться к разным данным.
Файловые tools этого прототипа принимают `x-local://`; сведения о поддержке
`x-app`/`file` самой платформой не расширяют schemas tools.

Для правки существующего текста получи текущие байты через `wshcm_read_file`
и используй его новый token. Search, старый чат и dryRun preview не заменяют
явное чтение нужных диапазонов в этом экземпляре MCP.

Проверяй `isError`, усечение и фактический результат операции. После неизвестного
исхода сначала выясни состояние сервера: потеря ответа не доказывает отсутствие
изменений. Skill и server instructions дают рекомендации; реальные проверки
задаются кодом tools. Они не создают изоляцию чатов или гарантии отката.

Skill самодостаточен при выборочной установке и не требует компилятора,
checkout репозитория или установленного `websoft-hcm`.
