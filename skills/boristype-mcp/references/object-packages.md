# Перенос объектов через ZIP

**Разовая выгрузка по ID.** Вызови на исходном стенде `wshcm_export_package`, передав `objectIds` массивом точных положительных десятичных строк, например `{"objectIds":["9007199254740993"]}`. Прямой режим сохраняет текущую схему админки и её состав. Для повторного экспорта из именованной схемы получи `schemaId` через `wshcm_list_package_schemas`, затем `revision` через `wshcm_get_package_schema` и передай их при экспорте. Настройка `includeRelatedObjects` использует типизированные связи формы. Зависимости, записанные строками или в `wvars`, сверь с фактическим составом.

**Проверь выгрузку.** Сопоставь `status`, `missingCount`, `missingIds` и `errors` с запросом. При `partial` ZIP может существовать с неполным составом. Для определений настраиваемых полей дополнительно проверь `missingCustomTemplates`. В прямом режиме `customTemplates: ["request_type"]` запрашивает все зарегистрированные шаблоны типа. Для самих карточек передай их ID в `objectIds`.

**Передай файл и проверь состав на целевом стенде.** `file.path` — путь на машине процесса MCP. Если оба MCP видят одну разрешённую папку, передай возвращённый путь как `inputPath` в `wshcm_inspect_package` целевого MCP. На разных машинах сначала перенеси ZIP в разрешённый проект или общую папку целевого MCP. Если целевому MCP доступно служебное хранилище экспортировавшего процесса, для просмотра также подходит `artifact.artifactId` до истечения срока хранения снимка. Чтобы оставить ZIP в репозитории, укажи `outputPath` в проекте уже при экспорте. Файлы общей папки MCP могут быть очищены после 24 часов.

**Применение.** Для задачи на просмотр достаточно inspect. Прочитай `items` и доступные страницы через `nextPage`. Для импорта используй возвращённый `inspectionId` в том же экземпляре целевого MCP. После его перезапуска повтори inspect. Если нужны конкретные элементы, укажи их `objectIds` или `packageIds` в `wshcm_import_package`. Без такого выбора инструмент обрабатывает весь снимок, включая элементы со следующих страниц. Определения полей, файлы, роли, списки и удаления включаются отдельными флагами. После применения перечитай нужный объект или определения на целевом стенде.

Если важна проверка исхода после таймаута, задай отдельный UUID `operationId` перед каждым изменяющим вызовом. Запроси `wshcm_get_package_operation` на том же стенде под той же учёткой. Статус `completed` с `verification: "platform_report_only"` подтверждает завершение штатной обработки пакета.

Прямой экспорт без изменения схемы и просмотр на целевой стороне проверены на Linux HCM 2025.2.1333. Имена параметров и доступные каталоги сверяй с описаниями инструментов установленной версии.
