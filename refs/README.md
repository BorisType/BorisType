Тематические входы описывают актуальное понимание. Датированные записи объясняют,
на каких данных оно основано. Исторический план, успешная сборка и непроверенная
гипотеза не являются подтверждением текущей поддержки.

Внутренняя база тоже находится в публичном git. Полные vendor runtime, секреты
и приватные данные стенда сюда не входят. Для внешних prerequisites указываются
условия получения и границы воспроизводимости.

## История миграции

Старые `ref/` и `plans/` разобраны по темам. [Итоговая запись](archive/documentation/2026-11-11-documentation-migration.md)
объясняет изменения и судьбу прежних правил, [migration-map.json](migration-map.json)
связывает 157 исходных материалов с окончательным местом знаний и исходным SHA256.
30 не-Markdown artifacts сохранены байт-в-байт. Markdown суммаризирован там, где
исторические планы и повторы мешали восстановить вывод; исходные blobs доступны
по baseline revision карты. Новые выводы не приписываются старым native запускам.
