# Исторические материалы

Снимки сохраняют контекст, который нельзя безопасно выбросить при первом проходе.
Они не являются текущими инструкциями или подтверждением готовности новой ревизии.
Устаревшие выводы и рекомендации сверяются по [актуальным тематическим входам](../README.md).

- [Архитектура прежнего compiler workspace](compiler/architecture/).
- [Исторические алгоритмы](compiler/algorithms/) и [предложения](compiler/proposals/).
- [Поколения refactoring/review](compiler/refactoring/): отдельные findings могут
  быть исправлены, опровергнуты или всё ещё актуальны. Их архивирование не закрывает задачи.
- [Dependency refresh](maintenance/2026-11-07-dependency-refresh.md): версии и проверки
  на дату изменения, а не обещание актуальности установленных зависимостей.
- [Старая структура документации](documentation/2026-02-26-structure.md),
  [ROADMAP](documentation/roadmap-before-migration.md),
  [KNOWN_ISSUES](documentation/known-issues-before-migration.md),
  [корневой README](documentation/readme-before-migration.md),
  [TODO](documentation/todo-before-migration.md).

Некоторые исторические ссылки уже были некорректны до миграции. Их наличие не делает
вывод доказанным; текущие маршруты проверяются отдельно. Соответствие источников
и исходных hashes — [migration map](../migration-map.json).

Дальнейшее сокращение возможно после проверки уникальных оснований, альтернатив
и открытых findings. Удалять все старые ревью одним действием не требуется.

Три сохранившиеся неразрешённые цели из старых материалов перечислены с причинами
в [link-exceptions.json](../link-exceptions.json). Они не разрешают добавлять битые
ссылки в актуальные справочники.
