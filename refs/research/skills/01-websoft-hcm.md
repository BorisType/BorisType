## Проверка полезности reference skill

исследованию. После авторства — только копия skill вне репозитория. Проверка
manual по содержательным ответам, без regex на формулировки.

| Сценарий                                 | Что должен дать справочник                                                                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |

| Замена запрещённого x-local на x-app     | Различие разрешения первого компонента, а не обещание эквивалентности схем.                                      |

| server и x-sys-image                     | Прикладной префикс и UI-ресурс; оба не преобразуются исследованным resolver.                                     |

Baseline `/root/skill_baseline`: ответ осторожный, без выдуманных параметров.
Недостающие знания обозначены явно. Например: «Совпадение файлов для всех трёх
схем не установлено»; «Без проверки я не могу подтвердить поведение функции»;
«Конкретный .ini-параметр для вашего Linux-сервера я достоверно назвать не могу».
Во всех пяти вопросах отсутствуют конкретные результаты, которые уже получены
исследованием. Это gap retrieval/reference, а не нарушение дисциплины;
запрещающие формулировки и pressure-тесты для его исправления не требуются.

## Дополнение по конфигурации

Без запуска остановленного стенда извлечены только `xHttp.ini` и `spxml2.ini`
во внешний research directory. В `xHttp.ini`:

- `DEFAULT-DATABASE: wt_data` — строка 4;
- повторяемые `DESIGN-DB` — строки 51–65, в том числе `wt`, `wtv`, `custom`, `platform`;
- повторяемые `DATA-DB` — строки 66–78, в том числе `wt_data`, `share`, `components`.

SHA256 `xHttp.ini`: `2df12d723ede6505468290cc05db84e92e3eb11e1d6bb33defca5c067fd9bcd5`.
SHA256 `spxml2.ini`: `9b1d37f80e45ee9f00b2dd4e455abd1f20e186f1461dcd1480d7a36551896c99`;
последний содержит только UI-language, перечисленных настроек там нет.

[Документация xHttp.ini](https://wshcm-docs.boristype.dev/news/monolith/6747986263544912377.html)
описывает DESIGN-DB как каталоги шаблонов, доступные администратору,
DATA-DB как каталоги чтения/записи сервера, DEFAULT-DATABASE как XML-базу/DefaultDb.
Конфигурация не изменялась, прямую причинную связь конкретного параметра
с `UrlToFilePath` отдельной конфигурационной пробой не проверяли. Не все
принимавшиеся ранее hosts присутствуют в этих списках: например, `app` и `Logs`.
