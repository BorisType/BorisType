# Agent skills в репозитории BorisType

**Date:** 2026-11-06

**Status:** Accepted

## Context

При исследовании WebSoft HCM накапливаются сведения о runtime, URL и настройках,
полезные независимо от компилятора и MCP. Их нужно передавать другим агентам
с источниками и границами применимости. Пользователь выбрал общий репозиторий,
чтобы знания платформы и инструкции инструментов поддерживались рядом.

## Decision

Размещать независимо устанавливаемые skills в корневой `skills/`, по одному
каталогу с `SKILL.md`. Стандартный layout поддерживается `npx skills add`,
включая выбор конкретного skill. Отдельный npm-пакет не нужен.

Первый `websoft-hcm` содержит переносимые сведения о платформе и путях.
Его references и собственные ограниченные probes входят в установленный skill;
обязательной зависимости от checkout, MCP, компилятора или стенда нет.
Специализированные инструкции инструментов могут появляться соседними skills.

Каждый технический факт сохраняет источник, версию/ОС/runtime/carrier и
границы доказательства. Vendor-файлы, credentials и локальная инфраструктура
не входят в распространяемое содержимое.

## Consequences

Знания и инструменты проходят review в одном месте. Установщик позволяет выбрать
только нужные skills. Изменения в skills сами по себе не меняют контракты tools.
References внутри каждого skill должны оставаться самодостаточными при
выборочной установке. Доступность remote install требует публикации изменений.

## Alternatives Considered

- Отдельный репозиторий знаний WebSoft: независимая история, но раздельное
  сопровождение platform skills и skills инструментов неудобно для текущей работы.
- Только `plans/` и проектные instructions: полезны для истории, но не дают
  самостоятельной выборочной установки переносимых знаний.
