Discover registered object types and catalog forms with `wshcm_list_object_types`, launch existing BorisScript server agents with `wshcm_run_agent`, and move one document to the HCM trash using `wshcm_delete_object` and a fresh full-read token.

The type registry includes native document associations and configured custom-field summaries. An exact type lookup can also return field definitions grouped by their templates.
