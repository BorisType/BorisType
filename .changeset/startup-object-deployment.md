`btc link` включает определения из `objects/<тип>/<ID>.xml` в поставку HCM. При запуске сервер перечисляет файлы, создаёт отсутствующие документы с заданными ID и применяет частичные изменения к существующим. `btc objects apply <файл> --dry-run` проверяет одно определение на работающем стенде.
