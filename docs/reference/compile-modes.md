# Режимы компиляции

В текущей версии доступен режим `bare`. Он используется по умолчанию.

| Режим  | Выходной код                                                                                  |
| ------ | --------------------------------------------------------------------------------------------- |
| `bare` | BorisScript с исходными сигнатурами функций и прямыми обращениями к свойствам и API платформы |

Режим определяет правила преобразования исходного TypeScript. Общие IR-проходы
обрабатывают управление потоком и ограничения парсера BorisScript.

## Выбор в btc

```sh
npx btc build
npx btc build --compile-mode bare
```

В первых 30 строках файла можно явно выбрать режим директивой:

```typescript
/// @bt-mode bare
```

Приоритет в `build`: директива файла, затем `--compile-mode`, затем режим
по умолчанию. Команда `dev` учитывает директиву и режим по умолчанию.
Недоступное имя режима приводит к ошибке.

## Программный API

`compile`, `compileFile` и `compileSourceFile` принимают `options.mode`.
Прямые вызовы API используют переданную опцию или режим по умолчанию.
`COMPILE_MODES` содержит доступные значения, а `DEFAULT_COMPILE_MODE` задаёт
значение по умолчанию.

## Ограничения bare

Исходные импорты удаляются, вызовы остаются обращениями к нативным функциям
и API хоста. Автоматической подстановки полифилов и общей эмуляции замыканий
нет. Подробности в [ограничениях BorisScript](./borisscript-constraints).
