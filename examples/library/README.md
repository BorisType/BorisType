# Пример библиотеки

Пакет с `ws:package: "library"` показывает, какие готовые файлы могут быть
скопированы при линковке зависимого пакета.

Из корня репозитория после установки зависимостей и сборки CLI:

```sh
pnpm -C examples/library build
```

Результат находится в `build/index.js`. Правила копирования файлов и требования
к их использованию описаны в [справочнике типов пакетов](../../docs/reference/package-types.md#library).
