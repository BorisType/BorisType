# Примеры BorisType

Примеры показывают компиляцию BorisScript и структуру поставки для разных
[типов пакетов](../docs/reference/package-types.md).

| Пример                       | Сценарий                                                        |
| ---------------------------- | --------------------------------------------------------------- |
| [single](single/README.md)   | Один пакет с конфигурацией линковки в `package.json`            |
| [multi](multi/README.md)     | Скомпилированный backend и статический frontend в одном `dist/` |
| [library](library/README.md) | Сборка файлов библиотеки для копирования в составе пакета       |
| [component](component)       | Структура компонента с метаданными `ws:package`                 |

Для компиляции используется [режим по умолчанию](../docs/reference/compile-modes.md).
Подготовка файлов инициализации для HCM описана в
[справочнике типов пакетов](../docs/reference/package-types.md).
